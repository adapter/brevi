Each sidebar repository gains a settings gear opening a per-repository settings page covering the default branch, Linear project routing, and that repo's stored memories. Repo editing and the memories list leave the Configuration page (its global memory knobs move to the Agent section), the sidebar's Usage row shows today's spend across all machines, and the Usage page adds 1-day and 365-day ranges. No npm package publishes; the change ships with the desktop app.
